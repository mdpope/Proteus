One chat layout on desktop, remote and web.

Explanation

All three views use the local desktop format and colors. Only local-file Open buttons are disabled in remote and web views. Paths remain visible and can be copied.

The plain + stays in position; its hover background is centered on the glyph. Option hover areas include the label and selection. Circular actions keep desktop sizing.

The editor grows upward as lines are entered or wrap. The composer can occupy up to 60% of the available chat area before the editor scrolls.

Switch views, resize the layout, add an attachment or try a long draft. Steer changes the current turn; the up arrow with a clock queues the next message. This is a synthetic review model; no messages, permission changes or uploads reach a host.
