## Completed-message actions — October 4, 2026

Completed assistant messages now have native Copy and Read Aloud buttons. Copy preserves the exact Markdown and shows transient copied feedback. Live streams, tool/permission events, reasoning/analysis events, user messages and empty messages do not receive these actions. Read Aloud starts only from the user's tap, uses one retained system synthesizer, and exposes Pause/Resume, Stop and an accessible Reading position slider beneath the active message.

The position is a percentage of the exact cleaned text, using the synthesizer's UTF-16 word-range callbacks. It is not an audio-duration estimate. Seeking restarts at the preceding word boundary; seeking while paused remains silent until Resume, and seeking to the end stops playback. Generation checks reject old completion/progress callbacks after replacement or seeking. Chat disappearance, chat/host/account changes, navigation to another main area, app deactivation and audio interruptions stop speech. Startup failure clears the active state and shows an inline error. No speech text/audio is persisted or sent to a model provider.

Speech uses `AVSpeechSynthesizer` with `usesApplicationAudioSession = false`; it does not change the shared app audio-session category/activation, request microphone or Personal Voice permission, add background modes, or change Omi processing. [Apple documents on-device synthesis](https://developer.apple.com/documentation/avfoundation/speech-synthesis), and its [speech-session guidance](https://developer.apple.com/videos/play/wwdc2020/10022/) covers retained synthesizers, separate system-managed speech sessions, assistive-technology settings, and available device voices. Voice availability/settings vary by device; Siri-specific voices are not exposed through this API. Headphone routing and coexistence with an actual physical recording session remain device acceptance, not simulator claims.

The new focused suite verifies Markdown-to-readable-text conversion (including links, images, tables, Unicode and literal code), exact clipboard content, event eligibility, one-message replacement, stale callbacks, finish/cancel/error cleanup, pause/resume, paused seeking and near-end seeking. A real system-synthesizer test receives word-range progress and confirms the shared audio-session category/mode/options are unchanged.
