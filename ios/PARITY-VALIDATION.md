# Native parity — October 4, 2026

The native source implements Home / Chats / Life / Team / Engine Room phone navigation and an iPad sidebar with group tabs, close/unload controls, contextual children, a touch/keyboard expander and delayed pointer-edge hover. Allowance is confined to phone Home or the iPad sidebar, with a persistent label-only collapsed state. The existing optional Life preference controls its content. The pairing screen no longer contains the tagline.

Chats read independent encrypted caches across all saved Macs and provide a host filter. Opening history does not select a new execution destination. Selecting a cached conversation can reconnect that conversation's own host; new chat execution remains explicit. Sidebar history is ordered across hosts. Message timestamps include the configured account timezone, with the device timezone as fallback. Unauthenticated relay refusal/revocation notices preserve keys, indexes, drafts and caches. Authenticated revocation is verified inside the encrypted, sequenced protocol before access is suspended; cached history remains available.

Team tools use the authenticated shared API for list/roster/link changes and browsing history. The native standup preserves fixed positions and shuffles the remaining members; iPad can dock it beside the other Team tools or present it separately. Browser descriptors are bounded, encrypted with a Keychain-held key, scoped to account, protected on disk and excluded from backup. Explicit saved links and restore descriptors preserve nonsecret query and fragment data so filters/searches reopen unchanged. Auth and pairing URLs/capsules are rejected before persistence; automatic history separately removes query and fragment data. Leaving Team unloads its WebKit pages; resources can unload or close them explicitly. No system browser history is imported. The native tab overview uses adaptive cards with titles, URLs, loaded/unloaded status and select/unload/close controls. WebKit link menus offer a new Proteus tab, the default browser, Copy Link, Download Linked File As and a draft on the explicitly named current Mac. The draft action preserves existing model/workspace/context choices and never starts a chat; Start chat remains a separate user action. Sensitive pairing/auth links cannot become drafts. Downloads use WebKit and a protected temporary file followed by the system Files export picker, with cancellation/account-change cleanup. iOS does not expose the default browser name here, so the label remains generic.

Shared API access requires explicit OAuth reconsent for `app:read app:write`. Existing Life-only tokens remain unchanged, and a failed or different-account upgrade preserves the previous sign-in. Mutations send expected account/workspace identity; shared data is cleared on account change. Providers remain configured on the host. Engine Room exposes host resources, usage, notification/log history, Connections, Account & Security and App Setup. Schedule completion notification preference preserves existing notification fields and revision/ownership restrictions.

APNs registration, failure handling, token submission, foreground presentation and cold/warm tap routing are implemented. Foreground connected-host alerts use generic local notifications without transcript data. An unmatched notification host never silently routes to another host. See `PUSH-SETUP.md` for the required paid-team push capability/profile and server credentials. The preserved signing profile does not enable APNs; no background-delivery acceptance is claimed.
